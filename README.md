# char2rig

**Из одной картинки персонажа — в готового к анимации 2D-персонажа.**

Конвейер, который берёт арт персонажа (нейрогенный или рисованный), автоматически режет его на части тела, достраивает скрытые области, собирает скелетный риг и применяет библиотеку анимаций. Максимум автоматики, правки — поверх, человек смотрит на результат, а не участвует в процессе.

## Зачем

Диффузионные модели хорошо генерят *картинки* персонажей, но для скелетной 2D-анимации (Spine / DragonBones / Godot Skeleton2D / Unity 2D Animation) нужна не картинка, а набор слоёв: части тела с нахлёстами в суставах, дорисованными перекрытыми областями, пивотами и порядком глубины. Этот проект автоматизирует путь от картинки до рига.

## Как это работает (кратко)

```
арт (PNG) → скелет (DWPose + шаблон) → сегментация (SAM2) → слои + inpaint
скрытого (LaMa/SD) → риг с нахлёстами → библиотека анимаций → экспорт в движок
```

Каждый этап кешируется и перезапускается независимо. Ручные правки хранятся оверлеями и переживают перегенерацию. После сборки конвейер сам гоняет стресс-тест (прокрутка суставов, рендер GIF) и флагает проблемных персонажей — вручную проверяются только они.

Подробности — в [DESIGN.md](DESIGN.md).

## Статус

🚧 **Фаза 0 — вертикальный срез** ([план](PLAN.md)). Конвейер целиком проходит на голом ядре, без единой модели: демо-кот режется на 17 частей, собирается в риг и машет конечностями. Швы на полосатом мехе держатся (щели 0.004% площади тела). Дальше — подключение DWPose/SAM2/LaMa и прогон на реальном арте. Интерфейсов нет, только CLI.

## Быстрый старт

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt      # ядро: numpy, pillow, opencv
.venv/bin/python -m char2rig demo              # процедурный кот → риг → GIF
```

Результат — в `characters/demo_cat/`: `preview.gif` (стресс-свинг),
`preview_strip.png` (та же анимация лентой), `layers/` (части с нахлёстами),
`rig.json`, `status.json` (чем сделан каждый этап и что показали проверки).

Свой арт:

```bash
.venv/bin/python -m char2rig process путь/к/арту.png --name barsik
.venv/bin/python -m char2rig edit barsik                    # подвинуть суставы
.venv/bin/python -m char2rig recut barsik --stage pose      # пересчёт с этапа
.venv/bin/python -m char2rig swing barsik                   # только превью
```

`edit` поднимает локальную страницу, где суставы двигаются мышкой. Правки
пишутся дельтами в `skeleton.overrides.json` и переприменяются при каждом
пересчёте — перегенерация арта их не стирает.

Свой обучающий набор с точной разметкой частей (карта «пиксель → кость» и
координаты суставов):

```bash
.venv/bin/python -m char2rig dataset --count 1000 --out dataset
```

Нейро-этапы (rembg, DWPose, SAM2, LaMa) подключаются доустановкой
`requirements-ml.txt` и включаются сами, если модели доступны; иначе каждый
этап уходит в фоллбек без моделей и пишет об этом в `status.json`. Флаг
`--no-ml` заставляет игнорировать модели даже когда они стоят.

## Требования

- Python 3.11+
- GPU с 8 ГБ VRAM (GTX 1070 подходит) — опционально, CPU-режим работает для штучной обработки
- Генерация арта и тренировка LoRA выносятся в облако (RunPod/Replicate)
