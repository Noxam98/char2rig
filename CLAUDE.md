# char2rig — контекст проекта

Конвейер «картинка персонажа → анимируемый 2D-персонаж» для 2D-игры друга
владельца репы. Целевой стиль — painterly кошачьи антропоморфы (полосатый
мех, digitigrade-ноги, хвост). Архитектура и все принятые решения —
[DESIGN.md](DESIGN.md), текущий план работ — [PLAN.md](PLAN.md).

## Договорённости с пользователем

- Общение — на русском.
- Максимум автоматики, решения принимать самостоятельно; спрашивать только
  про необратимое или смену скоупа.
- Ручные правки человека — оверлеи поверх автоматики, переживают
  перегенерацию (принцип №1 в DESIGN.md).
- Каждый нейро-этап имеет фоллбек без моделей; использованный фоллбек
  фиксируется в status.json персонажа.
- `samples/` в .gitignore — арт друга не публикуем без его согласия.
- Коммиты — по-английски, по делу; пушить в origin/main без вопросов.

## Окружение

- Рабочая машина: Windows 10 LTSC, GTX 1070 8 ГБ (драйвер 536.99;
  Pascal sm_61 → torch ≤ 2.7 / cu126), Python 3.13 в профиле пользователя.
  В PATH питона нет — звать `.venv\Scripts\python.exe`; venv в корне репы.
- Интернет рвёт большие загрузки: колёса тянуть через
  `curl.exe -C - --retry`, потом ставить локально из файла.
- Тяжёлое (SDXL-генерация, тренировка LoRA) — облако (RunPod/Replicate);
  локально живут DWPose, SAM2, LaMa, SD1.5-inpaint.

## Статус — обновлять при каждой значимой перемене

- **Сейчас:** фаза 0 пройдена на реальном арте. `samples/ginger.jpg` —
  painterly-кот от Gemini, `characters/ginger/` — результат. Все четыре
  модели работают на 1070 (torch 2.7.1+cu126), выводы про каждую — в PLAN.md.
- **Жёсткая нарезка признана тупиком:** превью и проверки идут деформацией
  сетки (`mesh.py`), персонаж гнётся как единое тело. Нарезка на слои
  осталась для экспорта в движки, смотреть её — `--preview parts`.
- **Инструменты правки** — `char2rig edit <имя>`: контур силуэта с узлами,
  кисть по силуэту, скелет с капсулами и толщиной, карта частей с кистью
  переноса, зум, сохранение и пересчёт из браузера. Строятся по порядку
  конвейера, снизу вверх; сделаны этапы 1 (силуэт), 2 (скелет), 3 (части),
  у 4 (достройка) готов и проверен бекенд.
- **Фронт переезжает на Vite + React + Zustand**, питон остаётся конвейером
  и бекендом. Контракт между ними — [API.md](API.md), менять его только
  правкой этого файла. Ваниль (`char2rig/editor.html`) живёт, пока фронт не
  заработает. Работы разведены по файлам: бек — `char2rig/*.py`, фронт —
  `web/`, уборка ванили — после.
- **Что дальше по порядку:** достройка (UI), веса сетки (из-за них поджимает
  концы конечностей), движения (сейчас это один зверский стресс-свинг с
  амплитудами в `render.SWING`, живой анимации нет).
- Образцов в `samples/` пока нет — демо-кот их не требует.
- На ноуте (Windows) venv собран под Python 3.13 из
  `%LOCALAPPDATA%\Programs\Python\Python313`; в PATH питона нет, звать
  через `.venv\Scripts\python.exe`.
- Открытые вопросы другу: движок игры, ракурс камеры, объём персонажей.
